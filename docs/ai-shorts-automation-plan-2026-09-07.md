# 골프여행 상품 AI 숏츠 제작 자동화 기획안

작성·자료 확인: 2026-09-07 / 대상: 골프조인 상품 광고

## 1. 제안과 검토 범위

**상품 데이터와 실제 현장 자료를 기반으로 대본·음성·자막·편집을 자동화하고, 생성형 영상은 선택적으로 추가하는 제작 시스템을 제안한다.** 첫 목표는 상품 5개로 광고 15편을 만들어 정확성·제작 원가·수정 시간을 측정하는 것이다. 초기 결과물은 담당자가 검수하고 내려받으며, 예약 게시와 광고 집행 연동은 이후 단계로 분리한다.

공식 API 문서, 제품 발표, 공식 가격표, 공급사 튜토리얼, n8n 커뮤니티 워크플로를 비교했다. 아래 기능 설명은 문서로 확인한 내용이며, 적합성·구축 일정·운영 목표는 이 프로젝트를 위한 기획 판단이다. 직접 API를 호출하거나 모델 간 영상 품질을 실측한 결과는 아니다. 커뮤니티의 '바이럴', '몇 분 완성', '고전환' 표현은 성과 근거로 채택하지 않았다.

실무용 API의 존재와 운영 가능성을 중심으로 검토했으며, 모든 최신 모델을 망라하거나 최고 성능 모델을 선정한 보고서는 아니다. 가격은 확인 시점 기준이며 웹앱 구독과 API 사용료를 구분한다.

## 4. 제작 방식 비교와 선택

아래 평가는 문서의 기능을 바탕으로 한 기획 판단이다. 상대적 비용에는 검수·재생성 부담을 포함한다.

| 방식 | 장점 | 부담·한계 | 사용 계획 |
|---|---|---|---|
| 실제 사진·영상 + 템플릿 편집 | 상품 충실도와 반복 제작 통제에 유리 | 사진만 쓰면 화면 변화가 단조로울 수 있음 | 기본 제작 방식 |
| 실제 자료 + 일부 AI 영상 | 장면 다양성과 자동화의 균형 | 생성 장면의 시설·지형 변형 검수 필요 | 대표 상품에 선택 적용 |
| 전 장면 생성형 영상 | 촬영 없이 다양한 콘셉트 시도 | 실제 상품 재현, 연속성, 재생성 원가 부담 | 브랜드 분위기 광고 실험 |
| AI 진행자 + 현장 자료 | 일정·혜택을 말로 설명하기 좋음 | 인물 호감도·발음·입 모양 확인 필요 | 설명형 광고 실험 |
| 기존 촬영 영상 자동 재편집 | 실제 현장감과 진정성 | 원본 영상과 이용 권한 확보 필요 | 원본이 있는 상품에 우선 적용 |
| ComfyUI 자체 생성 + 자체 합성 | 워크플로 통제와 공급사 교체 자유 | GPU 비용, 장애 대응, 모델 관리 | 초기 도입 보류 |

사진에 단순 확대·이동을 주는 편집과 생성형 Image-to-Video는 별도 옵션으로 표시한다. 단순 확대·이동은 원본 픽셀을 재배치하는 편집이고, 생성형 영상은 원본에 없던 내용을 만들어낼 수 있다. 실제 골프장·숙소를 소개하는 장면에서는 원본 영상 또는 단순 편집을 우선한다.

## 5. 권장 기술 구성

**1차: 기존 골프조인 상품 데이터 + n8n + 구조화된 대본 생성 + ElevenLabs + Creatomate + 프로젝트 저장소 + 검수 화면.**

- n8n: 상품 선택 요청, 각 제작 단계 실행, 상태 갱신을 연결한다. 이미 운영 가능한 작업 큐가 있다면 별도 도입 없이 기존 백엔드로 대체한다.
- 대본 생성: 모델에 상품의 검증된 사실과 사용할 수 있는 이미지만 전달한다. 장면별 화면 문구·음성 문구·사용 자료를 구조화해 반환하도록 한다. 특정 LLM의 우열은 이번 조사로 확정하지 않는다.
- ElevenLabs: 한국어 음성과 타임스탬프를 생성한다. 지명·골프장명·홀 수·금액의 발음 사전을 적용한다. 실제 음질은 동일 대본 청취 평가로 확정한다.
- Creatomate: 고정된 광고 템플릿에 장면·음성·자막·가격을 조립한다. API로 템플릿 요소 교체가 가능하다. [공식 예제](https://creatomate.com/docs/api/quick-start/create-a-video-by-template)
- 선택형 영상 생성: Runway 또는 Google 영상 API 중 검수 통과 비용이 좋은 공급사를 사용한다. 이미지 움직임이 꼭 필요한 장면만 생성한다.
- 저장소: 원본·음성·완성본·자막·제작 이력을 보관한다. Creatomate는 결과물을 최대 30일 보관한다고 안내하므로 제작 완료 후 자체 저장소로 복사한다. [보관 정책](https://creatomate.com/pricing)

**대안: Shotstack**은 장면 구성을 코드로 제어하는 팀에 비교 후보로 둔다. **Remotion + FFmpeg**는 자체 미리보기와 복잡한 일정 애니메이션이 필요해질 때 검토한다. FFmpeg는 자막·합성·확대 이동·음량 처리에 사용할 수 있다. 직접 구현 시 서버 운영과 폰트·미디어 호환성 관리가 추가된다. [Shotstack](https://shotstack.io/docs/guide/), [FFmpeg 필터 문서](https://ffmpeg.org/ffmpeg-filters.html)

Remotion은 무조건 무료인 선택지가 아니다. 공식 페이지는 개인·3인 이하 회사의 무료 사용과, 그 외 회사의 자동화 용도 사용량 기반 라이선스를 구분한다. 현재 자동화 회사 라이선스는 렌더당 $0.01, 월 최소 $100로 안내되어 있고 인프라 비용은 별도다. 실제 적용 범위는 계약 주체와 사용 형태에 따라 확인한다. [공식 라이선스](https://www.remotion.pro/license)

## 6. 골프조인 데이터 연결

확인한 로컬 계약 파일: `server/google-sheet-proxy-function/contracts/product-detail-snapshot-v1.schema.json`.

| 기존 필드 | 영상에서 사용 | 필요한 처리 |
|---|---|---|
| goodSeq, eventSeq, detailRevision | 상품·출발 행사·자료 버전 연결 | 같은 상품의 다른 출발일 혼합 방지 |
| title, duration | 상품명·여행 기간 | 긴 이름을 줄이되 고유명사 보존 |
| departureDate, returnDate | 출발·귀국일 | 지난 일정 제외, 게시 시점 재확인 |
| price, adultPrice, oilPrice | 가격 안내 | 기준 인원·포함 범위·유류할증료 중복 여부 확인 |
| includes, excludes, schedule | 혜택·일정 설명 | 명시된 사실만 사용 |
| heroImage, slides, introImages | 현장 시각 자료 | URL 접근성·해상도·상품 일치 확인 |
| detailStatus, sectionStatus, warnings | 제작 가능 여부 | 자료 불완전 시 누락 항목을 표시하고 해당 주장 생략 |
| sourceUrl | 상품 연결 | 채널별 사용 가능한 CTA와 추적 링크 생성 |

이는 데이터 구조가 존재한다는 확인이며, 실제 운영 데이터가 모두 채워져 있거나 광고용 권한이 확보되었다는 의미는 아니다. 골프장명·숙소명·총 라운드 수는 별도 구조화 필드가 충분한지 샘플로 점검한다. 단순히 필드가 없다고 LLM이 추정하지 않도록 한다.

추가할 항목: 광고 자료 사용 권한, 자료의 실제 장소, 세로 크롭 위치, 광고 가격의 적용 조건, 예약 가능 상태·확인 시각, 광고 유효기간, 채널, 템플릿 버전, 음성 버전, 제작비, 승인 이력, 게시 ID.

특히 현재 확인한 상품 상세 계약만으로 실시간 잔여 좌석을 보장할 수 없다. '마감 임박', '잔여 2석', '확정 출발'은 이를 뒷받침하는 별도 데이터가 있을 때만 허용한다.

## 7. 제작·검수 흐름

1. 담당자가 상품과 출발일, 광고 목적을 선택한다.
2. 상품 정보와 원본 자료를 특정 버전으로 저장한다.
3. 누락 정보·지난 일정·접근 불가 이미지·사용 권한을 검사한다.
4. 대본 후보 3개를 만든다. 원본 사실에 없는 가격·혜택·체험담은 사용하지 않는다.
5. 원본 이미지와 각 장면의 연결을 확인하고 세로 구도를 정한다.
6. 한국어 음성을 생성한 뒤 실제 길이에 맞춰 장면 길이와 자막을 정한다.
7. 선택한 장면에만 생성형 영상을 적용한다. 실패하면 원본 사진 편집으로 대체한다.
8. MP4와 자막, 표지, 채널별 소개 문구, 상품 연결 정보를 만든다.
9. 자동 검사를 거친 뒤 담당자가 가격·시설·발음·가독성을 확인한다.
10. 게시 직전 상품 가격·일정·예약 가능 여부를 다시 검사한다.
11. 검수한 결과물을 내려받거나, 이후 구현할 게시 기능으로 전달한다.
12. 소재별 조회·시청·상담·예약 성과를 연결해 다음 제작에 반영한다.

관리 화면은 상품 목록, 제작 설정, 진행 현황, 미리보기·수정, 게시·성과의 다섯 영역으로 구성한다. 수정 기능은 '첫 문구 바꾸기', '사진 교체', '발음 수정', '가격 갱신', '해당 장면 재생성'부터 제공한다.

상품 선택 직후 장시간 요청을 유지하지 않고 작업 번호를 반환한다. 생성 공급사의 작업 번호와 상태를 저장하고 웹훅 또는 제한된 상태 조회로 완료를 확인한다. 요청 시간 초과만으로 새 유료 작업을 만들지 않는다. 먼저 기존 작업의 완료 여부를 확인한다.

중복 생성 방지는 상품·행사·자료 버전·템플릿·대본·음성·비율 조합으로 판단한다. 장면별 재시도는 초기 정책으로 최대 2회, 예산 초과 시 검수 대기로 전환한다. 완성된 장면·음성은 재사용하되 최종 합성 비용은 다시 발생할 수 있다.

가격이나 일정이 바뀌면 아직 게시하지 않은 결과물은 재검수 대상으로 바꾼다. 이미 게시된 MP4는 원본 파일 변경만으로 갱신되지 않는다. 게시물·광고 ID를 저장해 해당 소재의 중단·교체 작업을 담당자에게 연결한다. 자동 중단을 구현하려면 별도 광고 관리 권한과 정책이 필요하다.

## 8. 첫 광고 템플릿 3종

| 유형 | 주요 질문 | 첫 문구 예시 | 강조할 자료 |
|---|---|---|---|
| 조건·가격형 | 무엇이 얼마에 포함되는가? | '[목적지] 골프여행, 포함 내역부터 확인하세요.' | 적용 조건이 명시된 가격, 라운드, 숙박 |
| 풍경·휴식형 | 어디에서 어떻게 쉬는가? | '다음 라운드는 [골프장명]에서.' | 실제 코스·객실·식사·휴식 시설 |
| 동반자·편의형 | 누구와 얼마나 편하게 갈 수 있는가? | '[출발일], 함께 떠날 골프여행을 찾으시나요?' | 실제 이동·일정·조인 조건 |

첫 문구는 실상품 확정 전의 틀이다. '노쇼핑', '2인 출발', '전 일정 포함', '최저가' 같은 표현은 근거가 있을 때만 삽입한다.

30초 기준 스토리보드:

| 시간 | 화면 | 음성·자막의 역할 |
|---|---|---|
| 0~3초 | 가장 매력적인 실제 코스 장면 | 대상 고객의 관심을 끄는 문장 |
| 3~9초 | 코스 1~2장면 | 장소와 확인된 라운드 구성 |
| 9~15초 | 실제 숙소·휴식 장면 | 숙박과 여행 경험 소개 |
| 15~23초 | 일정과 혜택 카드 | 포함 사항 최대 3개, 확인된 가격 조건 |
| 23~30초 | 출발일·브랜드·예약 안내 | 채널에서 실행 가능한 행동 하나 |

기본 출력은 1080×1920, 30fps, MP4 H.264/AAC로 제안한다. 이는 내부 제작 규격이며 채널별 업로드 검증은 별도로 한다. 자막은 최대 2줄을 초기 기준으로 하고, 핵심 문구를 채널 버튼과 겹치지 않는 위치에 배치한다. 큰 글자와 충분한 읽기 시간을 우선한다. 날짜·가격의 전체 설명을 30초 내레이션에 억지로 넣지 않는다.

처음에는 실촬영·사진 편집형을 기준 영상으로 만들고, 같은 대본에서 5초 정도만 생성형 장면으로 바꾼 버전을 비교한다. 자막·가격·로고는 생성 모델 영상 안에 직접 그리게 하지 않고 최종 편집에서 합성한다.

## 9. 제작 비용 모델

**월 총비용 = 도구 고정비 + 생성형 영상 비용 + 대본·음성 비용 + 렌더링 비용 + 저장·전송 비용 + 검수·수정 인건비.** 광고 매체비와 구축 인건비는 별도다.

Runway API는 현재 1크레딧=$0.01, Gen-4 Turbo=초당 5크레딧, Gen-4.5=초당 12크레딧으로 안내한다. [API 가격표](https://docs.dev.runwayml.com/guides/pricing/)

| 가정 | Gen-4 Turbo | Gen-4.5 |
|---|---:|---:|
| 생성 영상 5초, 1회 | $0.25 | $0.60 |
| 생성 영상 10초, 1회 | $0.50 | $1.20 |
| 편당 10초 × 평균 2회 × 월 100편 | $100 | $240 |

이는 생성 영상 비용만 계산한 예시이며, 실제 과금 대상 길이·성공률·해상도·추가 기능·세금에 따라 달라진다. 30초 광고에 생성 장면을 10초 넣는다고 가정했으며, 30초 전체를 생성한 비용이 아니다. 공급사 웹앱 구독 크레딧과 혼용하지 않는다.

Creatomate 공식 페이지는 720p·25fps 1분 영상을 약 14크레딧으로 예시하지만, 계획한 1080×1920·30fps 단가로 그대로 사용하면 안 된다. 실제 템플릿 1편을 렌더링해 크레딧을 측정해야 한다. 이번 페이지 조회에서는 월 결제 금액이 텍스트로 확인되지 않아 임의 월 구독료를 기재하지 않았다. [가격·크레딧 설명](https://creatomate.com/pricing)

최종 도구 선정 기준은 생성 1회 가격보다 **검수 통과 영상 1편당 총비용**이다. 재생성 횟수·수동 수정 시간·월 고정비 배분까지 기록한다. 로컬 GPU 방식은 GPU 사용시간뿐 아니라 유휴시간·장애 대응·관리 인건비를 포함해 비교한다.

## 10. 검증 기준과 실험 설계

파일럿: 상품 5개 × 템플릿 3종 = 기준 영상 15편. 상품은 이미지가 풍부한 상품, 이미지가 적은 상품, 긴 이름·복잡한 가격 조건이 있는 상품을 포함한다. 생성형 장면 비교는 기준 영상 중 3편을 복제해 실시한다. 한국어 음성은 같은 대본을 두 음성으로 만들어 담당자가 청취 평가한다.

검수 지표는 상품 사실 일치, 실제 시설 일치, 가격 조건 가독성, 음성 발음, 자막 타이밍, 브랜드 일관성이다. 자동 검사에서는 필수 문구·누락 파일·영상 길이·무음·검은 화면 후보·화면 밖 텍스트를 점검한다. OCR·음성 인식 결과는 보조 수단이며 사실 일치를 보증하지 않는다.

초기 내부 목표(실측 보장값 아님): 승인본의 상품명·가격·날짜 오류 0건, 15편 중 12편 이상은 장면 재제작 없이 검수 통과, 담당자 수정시간 중앙값 5분 이하. 제작시간과 원가는 실제 측정 후 운영 기준으로 확정한다.

광고 실험에서는 한 번에 첫 문구·장면 스타일 등 한 변수만 바꾼다. 유료 광고와 자연 유입을 분리하고 같은 기간·대상·예산 조건에서 비교한다. 15편 제작은 품질 검증용이며 통계적 광고 성과를 보장할 표본 수가 아니다.

성과는 채널 내 시청 유지·클릭과 사이트 내 상품조회·상담·예약을 연결한다. UTM에 상품과 소재 버전을 넣되, 프로필 이동처럼 소재별 추적이 끊기는 유입은 별도로 표시한다. 조회수만 높은 영상을 승자로 선정하지 않는다. 실제 유효 상담당 비용과 예약 전환을 우선한다.

## 11. 배포·광고 운영 범위

유튜브 쇼츠·인스타그램 릴스 업로드와 유료 광고 캠페인 집행은 다른 기능이다. 영상 생성 후 자동 게시가 가능하더라도 광고 계정 연결·예산·대상 설정·심사까지 자동으로 해결되는 것은 아니다.

YouTube는 미검증 API 프로젝트의 업로드를 비공개로 제한할 수 있다고 안내한다. Instagram은 프로페셔널 계정과 선택한 로그인 방식에 맞는 게시 권한을 확인해야 한다. 따라서 1차는 다운로드와 수동 게시, 2차는 계정 연동 후 예약 게시로 계획한다. [YouTube API](https://developers.google.com/youtube/v3/docs/videos), [Meta 공식 API 컬렉션](https://www.postman.com/meta/workspace/instagram/documentation/23987686-9386f468-7714-490f-9bfc-9442db5c8f00)

사실적인 생성·변형 장면을 사용하는 경우 플랫폼의 합성 콘텐츠 표시 요건을 게시 단계에 반영한다. 단순 대본 보조나 모든 AI 음성을 일괄적으로 동일 분류하지 않고 실제 사용 방식을 기준으로 판단한다. YouTube는 2026년 표시 방식 개선도 발표했다. [YouTube 안내](https://support.google.com/youtube/answer/14328491?hl=en-au), [2026년 표시 변경](https://blog.youtube/news-and-events/improving-ai-labels-viewers-creators/)

광고용 사진·음악·폰트는 이용 범위와 출처를 기록하고 승인된 자료 라이브러리에서 선택한다. 고객의 얼굴·목소리·후기를 사용할 경우 실제 사용 동의와 내용을 연결한다. AI 진행자는 여행 안내자 역할로 기획한다.

## 12. 구축 일정과 완료 조건

아래 일정은 개발 담당자 1명과 상품·마케팅 검수 담당자 1명, 사용 가능한 상품 자료와 API 계정이 준비된다는 가정의 추정치다. 계정 심사·권한 발급·자료 정리는 별도 지연 요인이 될 수 있다.

| 단계 | 기간 추정 | 산출물 | 다음 단계 진입 조건 |
|---|---|---|---|
| 자료 정리·벤치마크 | 1주 | 상품 5개 자료 세트, 대본 규칙, 음성 비교, 원가 기록 양식 | 실제 자료와 가격 조건 확인 |
| 제작 MVP | 2주 | 템플릿 3종, 상품 연결, 음성·자막·합성, 미리보기·다운로드 | 15편 검수와 오류 수정 완료 |
| 운영 안정화 | 1주 | 작업 이력, 재시도·중복 방지, 예산 제한, 부분 수정 | 실패·중복·가격 변경 시나리오 확인 |
| 채널·성과 연동 | 별도 1~2주 이상 | 예약 게시, 게시 ID, 소재별 추적, 성과 비교 | 계정 권한·게시 API 조건 충족 |

MVP에서 제외: 전 상품 무인 대량 게시, 광고비 자동 집행, 아바타 기본 적용, 전 장면 생성형 제작, 자체 GPU 인프라. 이후 도입 여부는 파일럿에서 측정한 추가 효과와 비용으로 결정한다.

착수 때 확정할 운영 항목은 주력 판매 대상, 월 제작량, 우선 채널, 사용 가능한 실제 영상, 브랜드 로고·폰트·음악, 가격 표시 기준, 월 운영 예산이다. 미확정 상태에서도 첫 설계는 한국어·30초·세로형·상품 5개·검수 후 다운로드를 기준으로 진행할 수 있다.

기획의 완료 산출물은 이 문서이며, 현재 계정 가입·유료 생성·영상 제작·채널 게시·서비스 코드 변경은 실행하지 않았다.
