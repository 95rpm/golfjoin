## 3. 변경 범위

최초 감지 시 복구 패키지 스냅샷과 비교한 결과는 추가 13줄, 제거 0줄이었다. 두 번째 변경 후 현재 파일은 스냅샷 대비 추가 25줄, 제거 2줄이다.

추가된 기능은 외부 딥링크 재개 작업의 동시 실행을 한 Promise로 합치는 잠금이다.

- `resumeJoinExternalDeepLinkOnce()`로 기존 실행 본문 분리
- `joinExternalDeepLinkResumePromise` 추가
- `resumeJoinExternalDeepLink()`의 진행 중 Promise 재사용
- 실행 종료 시 Promise 초기화

두 번째 변경에는 `my-section` 외부 딥링크를 로그인 뒤 재개할 때 필요한 쿼리 값을 보존하고, 첫 시도가 열리지 않으면 URL에 다시 기록해 재시도할 수 있게 하는 처리가 추가됐다.

- `mySectionParams`로 나의 모임 진입 파라미터 묶음 생성
- `continueMyHomeJoinDeepLinkAfterLogin()` 결과 확인
- 열리지 않았을 때 `golfjoinOpen=my-section`과 관련 값을 현재 URL에 다시 보존

회원별 모임 데이터가 늦게 준비되는 경우를 위해 보조 회원 데이터 로딩이 끝난 뒤 딥링크를 한 번 더 처리한다.

- `hydrateHomeSecondaryData()`의 회원 데이터 갱신 뒤 `await resumeJoinExternalDeepLink()` 실행
- 현재 확인 위치: `golfjoin_main.html:37258`

현재 위치: `golfjoin_main.html`의 `resumeJoinExternalDeepLinkOnce`, `resumeJoinExternalDeepLink` 주변.
