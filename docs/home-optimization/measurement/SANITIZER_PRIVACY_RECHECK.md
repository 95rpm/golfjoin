# HAR 개인정보 제거 도구 재검증

## 1. 발견 내용

3회차 제거본 검사 중 구조화된 `queryString` 값은 가려졌지만 HTTP/2의 `:path` 헤더 문자열 안에 URL 인코딩된 회원 식별값이 남는 경우를 발견했다.

- [x] 원본 HAR은 원래 민감정보를 포함할 수 있으므로 Git 제외 상태를 유지했다.
- [x] 제거본 외부 공유 전에 발견했다.
- [x] 기능 코드가 아니라 측정용 제거 도구만 수정했다.
- [x] 기존 run01·run02 제거본도 보강된 규칙으로 다시 생성했다.

## 2. 수정 내용

- [x] `:path`, `Referer`, `Referrer`, `Location`, `Content-Location` 헤더의 URL 쿼리도 제거한다.
- [x] 절대 URL과 `/path?query=...` 형태의 상대 URL을 모두 처리한다.
- [x] `:path`와 `Referer` 회귀 테스트를 추가했다.
- [x] 측정 도구 테스트 4/4가 통과했다.
