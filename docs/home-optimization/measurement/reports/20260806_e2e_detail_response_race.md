# 상품상세 비동기 응답 경합 E2E 기록

## 결론

상품상세 응답이 늦을 때 모달을 먼저 닫거나 다른 상품을 열어도 PC와 모바일 모두 현재 사용자가 선택한 화면 상태를 유지했다. 늦은 응답 때문에 닫힌 모달이 다시 열리거나 이전 상품이 새 상품을 덮어쓰는 현상은 재현되지 않았다.

이 검사는 조회 요청만 사용했다. 예약, 참여, 찜, 일정 생성 같은 운영 쓰기 요청은 실행하지 않았다.

## 시나리오 1 — 응답 대기 중 닫기

1. 새 로그아웃 Chrome으로 운영 메인에 접속한다.
2. `/goods/goods_view` 요청을 5초 지연한다.
3. MD PICK 상품상세 모달이 열리는 즉시 닫는다.
4. 클릭 전 스크롤 좌표가 ±3px 이내로 복원되는지 확인한다.
5. 지연한 응답이 도착할 때까지 기다린다.
6. 모달이 닫힌 상태와 스크롤 좌표가 그대로인지 확인한다.

결과:

- [x] 모바일 Chrome 통과
- [x] PC Chrome 통과
- [x] 늦은 응답 후 모달 재오픈 없음
- [x] 늦은 응답 후 스크롤 이동 없음

## 시나리오 2 — 이전 응답 전에 다른 상품 열기

1. 첫 상품 단계에서 시작한 모든 `/goods/goods_view` 요청을 보류한다.
2. 첫 상품 모달을 닫는다.
3. 두 번째 MD PICK 상품을 연다.
4. 두 번째 상품 제목과 상세 요청을 확인한다.
5. 보류한 첫 상품 요청을 다시 진행한다.
6. 첫 상품 응답이 도착해도 두 번째 상품 제목과 열린 상태가 유지되는지 확인한다.
7. 두 번째 모달을 닫고 두 번째 클릭 좌표가 ±3px 이내로 복원되는지 확인한다.

결과:

- [x] 모바일 Chrome 통과
- [x] PC Chrome 통과
- [x] 이전 상품의 늦은 응답이 새 상품을 덮어쓰지 않음
- [x] 두 번째 모달 닫기 후 스크롤 복원
- [x] 모바일 새 브라우저 3회 연속 통과

2026-08-07 재검증에서 테스트가 두 번째 상세 요청의 `route.continue()` 완료 전에 제목을 읽어 PC/MO 모두 15초 제한을 넘겼다. 실패 스크린샷의 실제 모달은 이미 두 번째 상품으로 정상 전환돼 앱 결함이 아님을 확인했다. 테스트를 `두 번째 요청 확인 → 두 번째 응답 완료 → 두 번째 제목 확인 → 보류한 첫 응답 해제 → 두 번째 제목 유지 확인` 순서로 보정했고 PC/MO 2/2를 재통과했다.

전체 PC/MO 6개 묶음의 첫 실행에서는 5개가 통과하고 마지막 모바일 회차가 두 번째 상품의 출발 가능일 조회 15초 초과로 중단됐다. trace에서 두 번째 클릭과 공통 로딩 시작은 확인됐다. 상태 경합 검사와 조회 성능을 분리해 모달 대기 한도를 45초로 설정한 뒤 모바일 경합 시나리오를 독립 브라우저 3회 반복했고 모두 통과했다. 스크롤 허용 오차는 ±3px 그대로 유지했다.

## 추가 관측

첫 상품 단계에서 `/goods/goods_view` 요청이 1건이 아니라 3건 시작됐다. 현재 테스트는 이 요청들을 첫 상품 단계 전체로 묶어 검증한다.

이 수치는 중복 호출의 증거로 단정하지 않는다. 상품군 구성 상품별 요청인지, 같은 상품의 중복 요청인지 URL의 `goodSeq`·`eventSeq` 조합과 호출 스택을 별도로 비교한 뒤 2단계 최적화 여부를 결정한다.

두 번째 상품의 출발 가능일 조회가 15초를 넘긴 회차도 확인했다. E2E의 45초 대기는 상태 정확성 검사를 위한 상한이며 목표 성능 기준이 아니다. 실제 조회 시간은 2단계에서 별도 측정하고 사용자 로딩 UI 및 중복 요청과 함께 개선한다.

## 시나리오 3 — 상품군 여행기간 연속 선택

1. 상품군이 있는 MD PICK 상세를 열고 여행기간 버튼이 2개 이상 표시되는지 확인한다.
2. 현재 기간과 다른 기간을 클릭한다.
3. 첫 전환이 처리 중일 때 원래 기간 클릭을 바로 예약한다.
4. 버튼 비활성화가 풀린 뒤 마지막 클릭이 실행되는지 기다린다.
5. 최종 선택 버튼이 한 개뿐이고 마지막으로 누른 기간의 `goodSeq`인지 확인한다.
6. 상품 제목이 마지막 선택 상품과 일치하는지 확인한다.
7. 모달을 닫고 최초 카드 클릭 좌표가 ±3px 이내로 복원되는지 확인한다.

결과:

- [x] PC Chrome 통과
- [x] 전환 중 중복 실행 차단
- [x] 마지막 클릭 기간만 단일 선택
- [x] 최종 상품 제목과 스크롤 복원
