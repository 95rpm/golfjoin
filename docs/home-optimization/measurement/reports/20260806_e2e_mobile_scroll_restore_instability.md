# 비로그인 E2E와 모바일 상세 닫기 스크롤 복원 불안정 기록

## 결론

PC Chrome의 로그아웃 메인 smoke는 통과했다. 모바일 Chrome은 메인 진입, 나의 모임 미노출, MD PICK 이미지, 상품상세 열기, 모달 뒤 메인 유지, 닫기 동작은 정상이나 닫은 뒤 스크롤 좌표가 간헐적으로 정확히 복원되지 않았다.

정밀 계측 결과 닫기 로직이 아니라 **카드 클릭 후 상품군 출발 가능일 조회가 끝난 뒤 페이지 좌표를 저장하는 순서**가 원인이었다. `golfjoin_main.html`은 카드 클릭 즉시 좌표를 저장해 상세 모달에 전달하도록 최소 수정했고 운영에 배포했다. 배포 후 강화된 모바일 검사를 3회 연속 통과하고 PC 회귀 검사도 통과했으므로 이 항목은 해결 완료로 판정한다.

## 자동 검사 순서

1. 새 브라우저 컨텍스트로 운영 메인에 접속한다.
2. 골프조인 루트와 MD PICK 카드를 기다린다.
3. 로그아웃 상태에서 나의 모임 섹션이 보이지 않는지 검사한다.
4. 첫 MD PICK 대표 이미지가 실제로 로드됐는지 검사한다.
5. 로딩 섹션 수, 루트 높이, 문서 높이, 섹션 수, 카드 수가 연속 4회 같을 때까지 기다린다.
6. 첫 카드를 클릭하는 이벤트 순간의 `window.scrollY`를 기록한다.
7. 상세 모달, 제목, 뒤 메인 영역 유지 상태를 검사한다.
8. 실제 PC 닫기 또는 모바일 슬라이더 뒤로가기 버튼을 클릭한다.
9. 최대 5초 동안 클릭 순간 좌표와 닫은 뒤 좌표의 절대 차이가 3px 이하인지 검사한다.

## 실행 결과

- PC Chrome: 반복 실행에서 통과.
- 모바일 단독 보정 확인: 1회 통과.
- 모바일 3회 반복 1차: 1회 통과, 2회 실패. 실패 편차 34px, 12px.
- 레이아웃 안정 판별 추가 후 모바일 3회 반복: 1회 통과, 2회 실패. 실패 편차 34px, 83px.
- 정밀 진단 3회: 클릭 좌표, fixed body 좌표, 복원 좌표가 모두 684px인 정상 회차 3회 통과.
- 기존 실제 흐름 5회 추가 반복: 3회 통과, 2회 실패. 실패 편차 12px, 34px.
- 실패 trace 1: 클릭 좌표 684px, 모달 잠금 좌표 696px, 닫은 뒤 696px. 편차 12px.
- 실패 trace 2: 클릭 좌표 684px, 모달 잠금 좌표 718px, 닫은 뒤 718px. 편차 34px.
- 닫기 로직은 저장된 값을 정확히 복원했으며, 비동기 출발 가능일 조회 중 페이지가 이동한 뒤 늦게 저장된 값이 직접 원인이다.
- 수정 배포 직후 기존 모바일 smoke 3/3, PC smoke 1/1 통과.
- 잠금 좌표 검사를 추가한 강화 모바일 smoke 3/3, PC smoke 1/1 통과.
- 강화 검사는 모바일 `body.style.top`의 절댓값과 카드 클릭 좌표, 닫은 뒤 좌표를 각각 ±3px로 검사한다.

## 후속 원칙

- 테스트 허용 오차를 늘려 통과시키지 않는다.
- 숫자 전용 진단기는 클릭 좌표, fixed body 잠금 좌표, 모든 `scrollTo` 목표와 모바일 visual viewport 변화를 함께 계측한다.
- 수정 전후 동일 모바일 3회 반복과 PC smoke를 모두 통과해야 완료 처리한다.
