# 모바일 레이아웃·상세 모달 스크롤 운영 검증

측정일: 2026-08-06 KST  
대상: `https://m.secret-tour.com/event/plan_view?eventPlanSeq=3&page=1`  
상태: Chrome Device Toolbar의 모바일 기기 모드, 로그인 상태, 운영 페이지  
목적: 모바일에서 가로 스크롤 재발 여부, 나의 모임 카드 시작 위치, 상품상세 모달의 배경 고정과 닫기 후 좌표 복원을 확인한다.

## 1. 결론

- [x] 모바일 URL이 `www`로 리디렉션되지 않고 `m.secret-tour.com`에 유지됐다.
- [x] 로그아웃 메뉴와 나의 모임 섹션을 확인해 로그인 상태에서 측정했다.
- [x] 문서 너비와 viewport 너비가 같아 페이지 전체 가로 스크롤이 없었다.
- [x] 나의 모임과 해외조인 BEST 첫 카드의 왼쪽 시작 위치가 정확히 같았다.
- [x] 상품상세를 열면 기존 페이지 위치가 고정되고 배경이 움직이지 않았다.
- [x] 상품상세를 닫으면 열기 전 위치로 정확히 복원되고 잠금 스타일이 제거됐다.
- [x] 로딩이 끝난 이미지 중 깨진 이미지는 0개였다.
- [ ] 정식 LCP·INP·CLS는 이번 기능 검증에 포함하지 않았다.

## 2. 모바일 레이아웃 측정

첫 측정 시 Chrome 가용 viewport는 412×915였다.

| 검사 | 결과 |
|---|---:|
| document clientWidth / scrollWidth | 412px / 412px |
| body scrollWidth | 412px |
| 골프조인 root clientWidth / scrollWidth | 412px / 412px |
| 나의 모임 섹션 왼쪽 | 25px |
| 나의 모임 첫 카드 왼쪽·너비 | 25px · 362px |
| 해외조인 BEST 섹션 왼쪽 | 25px |
| 해외조인 BEST 첫 카드 왼쪽·너비 | 25px · 362px |
| 완료 이미지 중 깨진 이미지 | 0개 |

개발자도구가 도킹된 Chrome 가용 영역이 321×714로 바뀐 뒤에도 다시 확인했다.

| 검사 | 결과 |
|---|---:|
| document clientWidth / scrollWidth | 321px / 321px |
| 나의 모임 섹션·첫 카드 왼쪽 | 25px / 25px |
| 해외조인 BEST 섹션·첫 카드 왼쪽 | 25px / 25px |
| 두 섹션의 카드 왼쪽 오차 | 0px |

화면 밖의 MD PICK 슬라이드 항목과 상단 칩 일부는 자체 가로 슬라이더 안에 존재한다. 문서 자체의 `scrollWidth`는 viewport와 같으므로 페이지 전체를 밀어내는 가로 넘침으로 판정하지 않았다.

## 3. 상품상세 스크롤 고정·복원

MD PICK의 `태국 우돈타니 로얄크릭 3박5일 로얄크릭` 카드를 사용했다.

| 시점 | document 위치 | body 상태 | 판정 |
|---|---:|---|---|
| 상세 열기 직전 | 1,241px | relative, 잠금 클래스 없음 | 기준 좌표 저장 |
| 상세 열린 동안 | 0px | fixed, `top: -1241px`, `width: 100%` | 배경 고정 |
| 열린 상태에서 스크롤 시도 후 | 0px | fixed, `top: -1241px` 유지 | 배경 이동 없음 |
| 상세 닫은 후 | 1,241px | relative, inline 잠금 스타일 제거 | 정확히 복원 |

- [x] `#detailModal.open`은 한 개만 존재했다.
- [x] 모달 열린 동안 `detail-modal-page-scroll-locked`, `modal-open`, `join-fullscreen-modal-open` 클래스가 적용됐다.
- [x] 닫은 뒤 위 클래스와 `top`, `left`, `right`, `width` inline 스타일이 모두 정리됐다.
- [x] 검증 종료 후 페이지를 맨 위로 되돌리고 모달이 닫힌 상태로 정리했다.
