## 개인정보 보호 방식

1. mark와 measure 이름은 코드에 적힌 고정 허용 목록만 사용할 수 있다.
2. 동적으로 만든 `golfjoin:detail:30001104` 같은 이름은 기록을 거부한다.
3. 로그의 중첩 객체와 배열을 작은 깊이까지만 복사하며 민감한 키의 값은 `[redacted]`로 바꾼다.
4. JSON 문자열도 다시 구조화해 민감한 필드를 제거한다.
5. 절대 URL과 상대 URL은 경로만 남기고 `?` 뒤 전체 쿼리와 `#` 조각을 제거한다.
6. 현재 로그인 회원의 알려진 이름·연락처·식별값은 일반 문자열 안에서도 `[redacted-private]`로 바꾼다.
7. 원본 `Error` 객체는 이름·마스킹된 메시지·코드·HTTP 상태만 남기고 stack과 응답 본문을 그대로 출력하지 않는다.
