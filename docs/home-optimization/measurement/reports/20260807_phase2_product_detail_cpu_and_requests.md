## 리스크 제한

- 상품군 구성, 대표 상품 우선순위, 가격, 출발일, 회원 일정 겹침 판정 결과는 바꾸지 않았다.
- 네트워크 URL, 요청 수, 파싱 방식, 서버 API는 바꾸지 않았다.
- 데이터 저장은 즉시 완료하고 화면 뒤쪽의 전체 홈 렌더 시점만 늦췄다.
- Builder가 실제로 열려 있으면 기존처럼 달력과 상품 목록을 갱신한다.
- 참여 신청·프로필 저장·취소 등 쓰기 경로는 변경하지 않았다.
- CookieData 캐시는 서버가 한 문서에 출력한 원문을 보관한다. 로딩 중 못 찾으면 같은 단계에서 반복 검색하지 않고 DOM 완성 후 한 번 확정하며, 로그인·로그아웃으로 이동하면 새 문서와 새 캐시가 만들어진다.
- 검증된 세션 회원 정보는 캐시한 CookieData보다 계속 우선하므로 오래된 서버 표식이 현재 회원을 덮어쓰지 않는다.
- 비로그인 단축은 회원키가 없을 때만 실행되며 로그인 회원의 나의 모임·일정 겹침 결과는 기존 경로를 그대로 사용한다.
