## 지연 응답 브라우저 검증

PC와 MO 각각 다음 순서로 자동검증했다.

1. 출발 가능일 응답을 보류하고 MD PICK 카드를 클릭했다.
2. 전역 로딩이 열리지 않고 클릭 카드만 `aria-busy` 상태가 되는지 확인했다.
3. 클릭부터 영역 안내 생성까지 140ms 이상인지 확인했다.
4. 응답 대기 중 메인페이지가 실제로 스크롤되는지 확인했다.
5. 응답을 풀고 상세 모달이 정상적으로 열리며 카드 로딩이 제거되는지 확인했다.
6. 상품군 기간 상세 응답을 다시 보류했다.
7. 기간 상자에만 영역 안내가 표시되고 상세 모달 내부가 스크롤되는지 확인했다.
8. 응답 전에 상세를 닫고, 늦은 응답 후 모달이 다시 열리지 않는지 확인했다.
