# 6단계 6-1 — 비로그인 V2 부트스트랩 기반 배포 전 검증

## 결론

- 판정: **배포 가능**
- 배포 대상: `golfjoin_main.html` 1개
- 최종 SHA-256: `8CD637AFED61D5ECDB432053DCE048C90450926E3692E72DAE2264069B81CFCE`
- 이번 배포에서 V2 기능은 기본 OFF이며 시작 경로에서도 호출하지 않는다.
- 따라서 일반 사용자에게 추가되는 V2 네트워크 요청은 0건이고, 기존 Legacy 화면과 데이터 경로를 그대로 사용한다.

## 초보자용 설명

이번 작업은 새 데이터 전환을 바로 켠 것이 아니라, 새 데이터를 안전하게 읽고 검사할 수 있는 전용 입구를 만든 것이다. 입구 앞에는 로컬 스위치와 서버 스위치가 모두 있으며, 현재는 로컬 스위치가 꺼져 있고 자동으로 입구를 호출하는 코드도 연결하지 않았다. 그래서 이 파일을 배포해도 고객 화면은 기존 방식으로 동작한다.

## 구현 체크리스트

- [x] 비로그인 사용자만 후보가 될 수 있도록 분리했다.
- [x] 로컬 명시 플래그가 `true`일 때만 V2 후보 로더가 동작한다.
- [x] Release manifest를 먼저 검증한다.
- [x] manifest의 원격 브라우저 플래그가 OFF이면 객체를 읽지 않고 Legacy를 유지한다.
- [x] 원격 플래그가 ON인 검증 상황에서 `homeCards`와 `liveHome`을 병렬로 읽는다.
- [x] GCS 버킷·release 전용 경로가 아닌 URL을 차단한다.
- [x] 논리 bytes, SHA-256, schema, release ID, watermark, role, data revision을 모두 검증한다.
- [x] 한 객체가 실패하면 같은 owner의 다른 요청을 중단한다.
- [x] 취소되거나 오래된 응답은 후보 데이터로 채택하지 않는다.
- [x] 실패한 세션은 회로 차단기를 열어 같은 실패를 반복하지 않는다.
- [x] 아직 `V2_COMMITTED` 또는 화면 데이터 적용을 수행하지 않는다.
