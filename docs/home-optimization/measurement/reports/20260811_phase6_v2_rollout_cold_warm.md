## 렌더 횟수 해석

- [x] 초기 로컬 캐시 화면 렌더 1회
- [x] 검증 완료 후 확정 V2 데이터 전체 렌더 1회
- [x] 기타 중복 전체 렌더 0회

총 함수 호출은 2회지만 역할이 다르다. 첫 번째는 네트워크를 기다리는 동안 빈 화면을 막는 즉시 로컬 화면이고, 두 번째만 서버 데이터 확정 후 실행되는 전체 렌더다. 초기 로컬 렌더를 제거하면 원격 OFF·오류·느린 네트워크에서 빈 화면 시간이 늘어나므로 유지한다.
