# Stage 13 전송 성능 예산 감사

## 결론

운영 `03A74294`는 HTML과 Critical CSS 예산을 통과했다. 전체 JavaScript는 gzip 336,658 bytes로 200KB 목표를 131,858 bytes 초과한다. Terser 안전 압축 시뮬레이션만 적용해도 gzip 259,950 bytes라서 목표보다 55,150 bytes 크다. 따라서 압축만 운영 반영하지 않고, 기능 경계를 먼저 분리한 뒤 압축하는 순서로 진행한다.

## 현재 전송량

| 자산 | 원본 | gzip | 목표 | 판정 |
|---|---:|---:|---:|---|
| 경량 HTML | 445,004B | 64,977B | 153,600B | 통과 |
| Critical CSS | 176,818B | 25,119B | 30,720B | 통과 |
| 전체 CSS | 853,185B | 101,380B | 참고 | gzip 유지 |
| JavaScript | 1,757,282B | 336,658B | 204,800B | 131,858B 초과 |

## 안전 압축 시뮬레이션

- 도구: `terser@5.50.0`
- top-level 제거 없이 압축·지역 이름 축약
- 문법 검사 통과
- 결과 원본: 1,143,145B
- 결과 gzip: 259,950B
- 목표 초과: 55,150B
- 운영 적용: 하지 않음

압축 자체는 약 76KB를 더 줄이지만 200KB 목표에는 도달하지 않는다. 압축본을 먼저 운영하면 다음 코드 분리의 원인 추적만 어려워지므로 후보로 승격하지 않는다.
