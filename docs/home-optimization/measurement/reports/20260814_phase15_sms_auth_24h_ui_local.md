## 쉬운 설명

일반회원은 아이디와 비밀번호가 맞아도 SMS 인증을 끝내기 전에는 로그인 완료 상태가 되지 않는다. 인증 도중 새로고침하면 이전 인증 화면을 억지로 복구하지 않고 안전하게 로그아웃된 메인으로 돌아간다. 인증을 완료하면 같은 탭에서 최대 24시간 동안 인증 상태를 갱신해 사용한다.

신규 일반회원은 회원정보 입력 단계에서 휴대폰 번호를 인증해야 다음 단계로 이동할 수 있다. 번호를 바꾸면 인증은 즉시 취소된다. 가입에 성공하면 같은 인증으로 24시간 회원 세션을 만들기 때문에 가입 직후 문자를 다시 보내지 않는다.

## 브라우저 검사 결과

| 항목 | PC 1440×900 | 모바일 390×844 |
|---|---:|---:|
| 인증 폼 폭 | 520px | 334px |
| 좌우 위치 | 중앙 | 좌우 28px |
| 입력 폰트 | 16px | 16px |
| 버튼 폰트 | 16px | 16px |
| 가로 넘침 | 없음 | 없음 |
| 인증번호 입력 | 정상 | 정상 |

모바일 아이디 로그인 폼도 폭 334px, 좌우 28px, 입력·버튼 16px로 측정되어 인증 화면과 일치했다. 로그인 인증번호는 서버 응답 `180초`를 받아 `03:00`부터 감소하며, PC·모바일 모두 정상이다. 인증 흐름 자체의 Console 오류는 0건이었다. 로컬 모의 서버가 상품 카탈로그와 실제 Secret Tour 쿠키를 제공하지 않아 발생한 예상 경고는 운영 회귀로 분류하지 않았다.

신규가입 휴대폰 인증은 PC에서 입력 69%·버튼 30%, 모바일에서 입력 68%·버튼 29%로 측정됐다. 두 화면 모두 `03:00` 타이머가 감소했고, 인증 성공 뒤 입력 행이 사라지면서 휴대폰 필드 오른쪽에 `인증완료` 배지가 표시됐다. 문서 가로 넘침은 PC·모바일 모두 0px였다.
