# 이벤트 16 게시판 스테이징 검증

## 1. 목적

운영과 같은 이벤트 게시판 HTML 입력·저장 경로에서 현재 골프조인 메인 HTML이 잘리지 않고 실행되는지 확인하고, 이후 변경본을 운영 반영 전에 검사할 테스트 페이지를 확보한다.

## 2. 대상

- PC 직접 주소: `https://www.secret-tour.com/event/event_view?eventPlanSeq=16&page=1`
- 모바일 진입 주소: `https://m.secret-tour.com/event/event_view?eventPlanSeq=16&page=1`
- 등록 파일: `golfjoin_main.html`
- SHA-256 2회 확인: `8A853CA11B9DED569067D2E45317B883E44452868E7FA8E01A2CCFAD6A17ACCC`
- 크기: `2,731,639 bytes`
- 로컬 수정 시각: `2026-08-06 10:51:10 KST`

## 3. 게시 상태와 Probe 확인

- [x] 미노출 상태에서는 이벤트 목록에서 16번이 사라진다.
- [x] 미노출 상태에서는 직접 주소에서도 본문 HTML이 렌더링되지 않는다.
- [x] 노출 상태에서 공개 목록에 `테스트` 카드가 표시된다.
- [x] 노출 상태의 PC 직접 주소에서 `#golfjoin-staging-probe-16`이 `display:block`, `visibility:visible`로 표시된다.
- [x] 노출 상태의 모바일 진입 주소에서도 같은 Probe가 표시된다.

설명: 이 게시판의 `미노출`은 목록만 숨기는 설정이 아니라 본문 출력까지 막는다. 현재는 고객 노출이 허용된 테스트 기간이므로 이벤트 16을 노출 상태의 공개 테스트 페이지로 사용한다.

## 4. 전체 HTML 등록 결과

- [x] HTML 끝부분의 `#builderActiveScheduleSheet`, `#builderProductDetail`, `#joinActionLoadingOverlay`가 모두 존재한다.
- [x] 핵심 상품 섹션 3개가 렌더링된다.
- [x] 일반 상품카드 6개와 MD PICK 카드 4개가 렌더링된다.
- [x] 문서 높이 5,932px, 화면 높이 911px 상태에서 실제 세로 스크롤 이동이 가능하다.
- [x] MD PICK 대표이미지 4개가 모두 `naturalWidth:800`으로 로드된다.
- [x] 검사 시점에 보이는 이미지 46개 중 깨진 이미지가 없다.
- [x] 수집된 콘솔 오류가 없다.

## 5. 상품상세 검증

- [x] 첫 MD PICK 상품의 상세 모달이 열린다.
- [x] 상품명, 여행기간, 포함사항이 표시된다.
- [x] 상세 이미지 19개가 모두 정상 로드된다.
- [x] 최종 상태에서 공통 로딩 오버레이는 `opacity:0`, `visibility:hidden`, `pointer-events:none`이다.
- [x] 상세 모달을 닫으면 본문 스크롤 잠금이 해제된다.
- [x] 닫은 뒤 상품카드 기준 위치 727px로 복원된다.
- [!] 카드 클릭 3.5초 뒤 DOM 검사와 초기 진입 직후 검사에서 각각 한 차례 검사 컨텍스트 시간 초과가 발생했다. 추가 대기 뒤 정상 완료되었으므로 등록 실패가 아니라 기존 초기 렌더·상세 초기화의 메인 스레드 점유 병목이 테스트 페이지에서도 재현된 것으로 기록한다. 정확한 시간은 최적화 전후 Performance trace로 비교한다.

## 6. 모바일 검증

- [x] 모바일 진입 주소가 `www` 직접 주소로 연결된 뒤 동일 HTML을 로드한다.
- [x] 자동 검사에서 핵심 섹션·카드·끝부분 마커와 MD PICK 이미지 4개가 확인됐다.
- [x] 사용자가 Chrome 390×844 모바일 화면에서 스크롤, 상품상세, 배경 유지, 닫기 후 위치 복원을 확인했고 모두 정상이라고 판정했다.

## 7. 결론과 운영 결정

- [x] 이벤트 16을 운영과 같은 게시판 저장 경로의 공개 테스트 페이지로 사용할 수 있다.
- [x] 현재 `8A853...` HTML의 등록·기능 검증이 통과했다.
- [x] 이벤트 16은 전체 HTML이 등록된 현재 상태로 유지한다.
- [x] 의도적으로 HTML을 제거한 뒤 다시 등록하는 반복 시험은 진행하지 않는다. 기존 운영 페이지 실제 복원 경험, `8A853...` 복구 ZIP의 4.253초 격리 복원, 이벤트 16의 Probe→전체 HTML 등록과 PC/MO 기능 검증으로 필요한 복구 경로가 이미 확인됐다는 사용자 운영 결정을 반영한다.
