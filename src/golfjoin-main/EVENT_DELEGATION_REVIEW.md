# 이벤트 리스너·위임 검토

## 초보자를 위한 결론

버튼마다 클릭 감시자를 계속 새로 붙이면 화면을 다시 그릴 때 같은 동작이 두 번 실행될 수 있다. 상위 영역 한 곳에서 클릭을 받아 실제 버튼을 찾는 방식을 이벤트 위임이라고 한다.

현재 골프조인 메인은 동적으로 다시 그리는 주요 영역에서 이미 이벤트 위임을 사용한다. 전역 `window`·`document` 정적 연결은 메인 스크립트가 한 번 실행될 때 한 번만 만들어지며, 빌드 산출물 PC/MO E2E 12/12에서 중복 반응은 발견되지 않았다. 3단계는 바이트 동일한 구조 이동 단계이므로 리스너 통합까지 함께 변경하지 않는다.

## 판정

| 구분 | 현재 판정 | 이유 |
|---|---|---|
| 동적 필터·모달 버튼 | 유지 | `periodButtons`, `sortButtons`, 회원가입 폼, 여행지 모달 등은 상위 요소 클릭 위임을 사용한다. |

| 요소별 touch·transition | 유지 | 새로 생성된 카드·달력·슬라이드 요소의 생명주기에 붙으며 전역 위임으로 바꾸면 제스처 상태가 섞일 수 있다. |

## 재검토 조건

- 같은 클릭 한 번에 모달이나 API가 두 번 실행될 때
- render 함수 안에서 기존 DOM에 리스너를 반복 등록하는 새 코드가 들어올 때
- 7단계에서 섹션별 선택적 렌더를 도입할 때
- `resize` trace에서 같은 프레임의 중복 전체 레이아웃이 확인될 때
